understandable.

What this website does, and which third-party services may be used by the launcher.

LAST UPDATED · 03 NOVEMBER 2026

1. This website

The public Eclipse Client website is a static information and download website. The supplied website project does not include a visitor account system, a contact-form database, advertising trackers or a first-party analytics service. The site requests optional typography files from Google Fonts; that provider may receive standard browser request information. The site loads optional typography files from Google Fonts, which may receive standard browser request information. Vercel may process request and deployment data as part of hosting and security operations under its own terms.

2. Launcher data

The desktop launcher has features such as Microsoft sign-in, local profiles, Minecraft instances, content downloads, optional Discord Rich Presence and skin-provider configuration. Data may be processed locally by the app or by the relevant third-party services when you choose to use those features. Review Microsoft's, Discord's, Modrinth's and any skin provider's privacy documentation when using those services.

3. Local files and profile data

Minecraft instance files, configuration, local profiles and downloaded content may be stored on your device. The launcher does not operate a cloud skin-hosting service as part of the documented release.

4. Third-party services

Microsoft authentication, Modrinth content, Discord Rich Presence, GitHub release downloads and supported skin providers are independent services. Their own privacy terms and availability apply.

5. Contact

A verified public privacy contact address has not been configured for this website. The project should publish a monitored contact channel before collecting user submissions or personal information through additional services.
