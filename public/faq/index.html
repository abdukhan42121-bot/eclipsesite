GOOD TO KNOW

Questions, meet
clear answers.

Details about accounts, content compatibility, installation and the services Eclipse connects to.

Which operating systems are supported?

The current launcher release is built for Windows 10 and Windows 11 on x64 systems. The published setup file is a Windows installer.

Do I need Node.js to use Eclipse?

No. Node.js is used by the development/build process. The packaged setup includes Electron and the production dependencies required by the launcher.

Can I sign in with Microsoft?

Yes. Eclipse includes a Microsoft sign-in flow for supported authenticated Minecraft play. You can also create a local profile for supported offline and singleplayer use.

Can local profiles join every server?

No. A local profile does not provide a paid Minecraft licence or Microsoft authentication. Servers that require authenticated premium accounts will continue to require them.

What content can I install?

Eclipse integrates Modrinth content for compatible mods, modpacks, resource packs and shaders. Required mod dependencies are installed based on the metadata supplied by the project.

Will my local skin or cape be visible to everyone?

Not automatically. Local skin and cape files remain local unless configured with a supported provider. Other players need compatible skin support and provider configuration for shared visibility.

How does Discord Rich Presence work?

Enable Show Eclipse in Discord under Settings. The Discord desktop application must be running and signed in. You can turn the feature off at any time.

Is Eclipse affiliated with Mojang or Microsoft?

No. Eclipse Client is an independent community project and is not affiliated with, endorsed by or sponsored by Mojang or Microsoft. Minecraft is a trademark of Microsoft Corporation.

Is the installer code-signed?

The current distributed setup is not code-signed. Windows may display an unknown-publisher warning. Only download from the official release location and do not disable security protections.
