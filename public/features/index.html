THE ECLIPSE TOOLKIT

Everything you need.
Nothing you don't.

Designed around the parts of Minecraft setup you return to: profiles, compatible content, personalisation and the controls that make a session yours.

PROFILESMODRINTH CONTENTWARDROBESETTINGS
01 / INSTANCE MANAGEMENT

Profiles with their own space.

Create separate profiles for different Minecraft versions and playstyles. Each profile keeps its own game directory, mods, resource packs, shaders and settings so one setup does not casually spill into another.

02 / ACCOUNT OPTIONS

Sign in your way.

Use Microsoft account sign-in for supported authenticated play, or create a local profile for supported offline and singleplayer use. Local profiles do not grant access to servers that require a paid Microsoft account.

03 / MODRINTH INTEGRATION

Content that fits the profile.

Browse mods, modpacks, resource packs and shaders. Eclipse checks Minecraft version and loader metadata for supported Modrinth installs and follows required dependency metadata for mods.

04 / WARDROBE

Make the character yours.

Manage local skin and cape files in the selected instance. Eclipse can configure a supported skin loader/provider, but it does not host a cloud skin service. Shared visibility depends on provider setup and compatible client support.

05 / DISPLAY & MEMORY

Put the controls in reach.

Adjust launcher and game resolution, memory allocation and related preferences from the desktop launcher. Actual available memory is still limited by the computer and other running applications.

06 / DISCORD PRESENCE

A little context for friends.

Optional Discord Rich Presence can show Eclipse activity while the Discord desktop app is running and signed in. It can be switched off in launcher settings.

Compatibility depends on the Minecraft version, loader, upstream Modrinth metadata and third-party services. Check each project's page and licence before installing it.
