Important information about the independent Eclipse Client project and third-party content.

LAST UPDATED · 03 NOVEMBER 2026

1. Independent project

Eclipse Client is an independent community project. It is not affiliated with, endorsed by, or sponsored by Mojang or Microsoft. Minecraft is a trademark of Microsoft Corporation.

2. Software availability

Features, compatibility and download availability may change between releases. The website describes the documented launcher scope; individual integrations can depend on upstream services, account status, Minecraft version, loader and system configuration.

3. Third-party content

Mods, modpacks, resource packs, shaders, account authentication and skin-provider services may be supplied or operated by third parties. Their licences, terms, project rules and compatibility requirements apply. Review the project page and licence before installing third-party content.

4. Accounts and servers

Local profiles are intended for supported offline and singleplayer use. They do not provide Microsoft authentication or a Minecraft licence, and they do not bypass the requirements of servers that require authenticated accounts.

5. Safe installation

Only download the Windows installer from the official release asset linked by this website. The current installer is not code-signed and Windows may display an unknown-publisher warning. Do not disable Windows security protections to run unverified software.

6. No warranty

The software is provided as an independent community project. Back up important Minecraft worlds and instance data before making significant changes to game files or installing third-party content.
