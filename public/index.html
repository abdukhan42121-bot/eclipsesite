Which Minecraft versions does Eclipse support?＋

Eclipse is designed to manage separate Minecraft profiles. The available versions and loaders depend on the launch components and compatible metadata available when you install them.

Can I use Microsoft sign-in?＋

Yes. The launcher includes a Microsoft account sign-in flow. You can also create a local profile for supported offline and singleplayer use.

Can I install mods and modpacks?＋

Yes. Eclipse integrates Modrinth content for compatible mods, modpacks, resource packs and shaders. Required dependencies are handled where the project metadata provides them.

Will my local skin or cape automatically be visible to everyone?＋

No. A local texture is not automatically public. Shared visibility depends on a supported skin provider and compatible configuration on the clients that need to display it.

Does Eclipse work with Discord?＋

Yes. Discord Rich Presence can be enabled in Settings. The Discord desktop app needs to be running and signed in.

Is Eclipse affiliated with Mojang or Microsoft?＋

No. Eclipse Client is an independent community project and is not affiliated with, endorsed by or sponsored by Mojang or Microsoft.
