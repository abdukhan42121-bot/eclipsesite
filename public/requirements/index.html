BEFORE YOU INSTALL

Know your setup.
Then get playing.

Eclipse is a Windows-first Electron launcher for Minecraft Java Edition. Here is what to prepare before installing.

FabricInstalled per profile

Installation steps

  1. Download Setup from the official release link.
  2. Open the installer and choose an install location.
  3. Choose whether to create a desktop shortcut.
  4. Launch Eclipse from the Start Menu or shortcut.
  5. Create or sign into a profile, then select a game setup.

Important compatibility notes

The launcher can download and manage game components, but Minecraft itself still has its own performance requirements. Mod, modpack and shader compatibility depends on the Minecraft version, loader and project metadata. Some servers require a Microsoft-authenticated account; a local profile does not bypass that requirement.
