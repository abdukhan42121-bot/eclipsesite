WINDOWS LAUNCHER · v0.7.1

Eclipse Client 0.7.1

The launcher release includes isolated profiles, Microsoft and local profile options, Vanilla and Fabric launch support, Modrinth content installs, Wardrobe, display settings and optional Discord Rich Presence.

  • Windows x64 setup wizard with selectable install location.
  • Start Menu shortcut and optional desktop shortcut.
  • Launch-after-install option and uninstaller.
  • Packaged Electron runtime; end users do not need Node.js.
